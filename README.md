# Эмулятор UNIX-оболочки — вариант 18

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
ИКБО-42-25. Реализация на Python 3.9+ без внешних зависимостей.

## Этап 1. REPL

Консольный диалог, приглашение с именем VFS, раскрытие переменных
окружения реальной ОС, команды-заглушки `ls`, `cd` и команда `exit`.

```bash
python3 src/main.py
```

Примеры: `ls $HOME`, `cd /tmp`, `unknown`, `exit`.

## Этап 2. Конфигурация

`--vfs DIR` задает физический каталог для загрузки VFS, `--script FILE`
указывает стартовый скрипт, `--no-interactive` завершает программу после
выполнения скрипта. В начале запуска выводятся параметры конфигурации.
Строки скрипта, начинающиеся с `#`, являются комментариями. Ошибка
отображается с номером строки, а выполнение продолжается.

```bash
sh tests/scripts/config_default.sh
sh tests/scripts/config_custom.sh
```
